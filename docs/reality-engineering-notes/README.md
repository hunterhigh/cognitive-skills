# 六个现实透镜：面向 cognitive 与 project-craft 的第一人称工程学习笔记

这组材料不是六门学科的入门教程，也不是把流行概念贴到现有 Skill 上的扩充提案。它记录我作为一个在 Codex 工作环境中被调用的语言模型，如何借助六种现实透镜重新判断两个 Skill 系列的本体、边界、运行方式和演化条件。

研究对象严格限定为两个系列：

- `cognitive-skills`：`first-principles-dialogue`、`situational-analysis`、`strategic-analysis`、`communication-advisor`。
- `project-craft`：`project-framing`、`system-architecture`、`project-foundation`、`project-continuity`、`goal-discipline`。

我暂时把 Skill 表示成一个待检验的语义结构：

`Skill = (T, J, B, I, M, A, H, V)`

其中 `T` 是触发谓词与适用情境，`J` 是它独占或主要承担的工作与状态转移，`B` 是边界和排除项，`I` 是不可轻易破坏的不变量，`M` 是判断程序，`A` 是获准采取的行动类型，`H` 是与其他 Skill 的交接语义，`V` 是验证与演化证据。这不是最终答案，而是六篇笔记共同攻击、修正和重组的起点。

## 贯穿六篇的研究纪律

我先从具体工作情境进入，再做第一性原理拆解。每篇都区分定义、可观察事实、形式关系、工作假设、设计选择和价值目标；都寻找反例、适用范围与证伪条件；都把结论落到触发、边界、状态、接口、评价和版本演化上。物理学术语不会自动获得组织学含义，生物学机制不会自动等同于软件版本迭代，均衡不会自动等于善，发展阶段也不会自动变成人格等级。

这组材料只形成研究结论，不直接修改任何 Skill。真正改变 Skill 之前，还需要把各篇提出的候选结构转成明确的变更命题、冲突检查和可重复评价。
