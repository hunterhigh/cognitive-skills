# 事实清单模式

当用户要求事实清单、原子事实清单、事实 inventory，或要求先收集公理、事实、假设、复杂命题和数理关系时，使用本模式。

输出必须只包含以下五个一级标题，不能增加其他一级标题：

```markdown
# 公理（常识性知识/物理事实/数理事实）
# 原子事实
# 假设
# 复杂命题
# 数理关系
```

每个标题下只写编号行，不加表格、项目符号、前言或总结。

每一行必须能够具有真值，或是可以检验的数学／逻辑关系。不要把愿望、口号、修辞问题或模糊偏好写成事实。未解决问题若要进入清单，改写为可判真的状态命题，例如“指标 X 尚未知”或“当前没有证据证明 X 导致 Y”。

假设只保存为了继续推理而暂时采用、以后可以检验的命题。目标、设计选择、研究问题和指标代理不能伪装成假设；必要时在行内标明其真实类型，或不放入该固定格式而先向用户说明格式不足。

复杂命题必须能追溯到清单中的原子事实、公理、假设和关系。不能只因听起来合理就写入。
