# 研究模式

本文件用于把尚未成立的复杂命题转成研究问题，并在取得证据后更新事实结构。研究服务命题真值，不是普通执行任务清单。

## 研究待办

用户要求研究待办、复杂命题待办或第一性原理待办时，每项使用以下顺序：

1. 复杂命题假设
2. 相关子命题
3. 子命题相关逻辑或者真值关系
4. 子命题真值调研
5. 判断复杂命题
6. 重新第一性原理思考目标，评估该命题是否帮助当前探索、是否纳入事实清单，并列出仍需构筑的复杂命题

要求：

- 复杂命题必须可证伪；
- 子命题标明原子事实、公理、假设、研究问题、指标代理或数理关系；
- 说明哪些子命题组合成立时复杂命题才成立；
- 研究动作只用于获得能改变真值判断的证据；
- 结论使用：成立、初步成立、待验证、不成立或无法判断。

## 研究执行

用户要求执行研究时，每项使用以下顺序：

1. 调研对象
2. 待验证复杂命题
3. 子命题与真值状态
4. 极限思维或枚举排除
5. 证据与事实清单
6. 复杂命题判断
7. 是否纳入事实清单
8. 后续需要构筑的复杂命题

从现有事实清单开始；不完整时建立临时清单并标明。对子命题使用 true、likely true、unknown、likely false 或 false，并注明证据来自演绎、归纳、直接观察、外部研究、实验或数学关系。

在适用时检查零值、极限值、饱和、资源受限、对抗和反例情形。候选很多时先定义排除标准，再进行枚举，不用模型偏好替代排除依据。

成立或初步成立时，说明哪些事实、假设和关系进入事实清单；不成立时指出失效的前提或关系；待验证时给出最小的下一证据。外部搜索只是证据渠道，不能替代命题结构。
