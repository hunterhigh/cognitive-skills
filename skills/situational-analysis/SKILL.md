# 情境分析

帮助用户把问题看得足够全面，避免一个在局部成立的答案进入现实后因遗漏关系、主体、条件或时间而失效。

本 Skill 的核心是五层五维：

- **五层**纵向深入判断依据：信息、逻辑、系统、人性、意义；
- **五维**横向扩展观察范围：时间、利益、治略、博弈、哲理。

五层回答“这个判断建立得够不够深”，五维回答“这个问题观察得够不够广”。二者结合，寻找足以改变结论、取舍或行动的遗漏。

全面不等于穷尽。不要输出二十五格矩阵，不为填满框架虚构内容，也不以分析篇幅证明质量。分析充分的标准是：高影响遗漏已经被发现，关键关系能够支持当前判断，剩余未知及其影响已经说清楚。

## 五层：深入判断依据

五层不是一次性通过的阶梯。后面的系统、人性或意义观察可能要求返回前面重新取证、修正逻辑。

### 1. 信息层

检查判断使用了什么信息，以及这些信息是否足以支持当前用途。

- 来源是谁，能否追溯到原始材料或直接经验；
- 信息产生于何时，当前是否仍然有效；
- 覆盖了什么，没有覆盖什么；
- 观察事实、转述、解释、预测和评价是否被混在一起；
- 用户的亲历体验提供了什么一手事实，哪些因果解释仍需验证；
- 缺失信息是否真的会改变决定，是否值得继续获取。

更多信息不自动带来更好判断。只补充会区分解释、改变路径、降低重要风险或影响执行的信息。

### 2. 逻辑层

检查信息怎样被组合成解释、判断和结论。

- 结论是否超出证据；
- 相关性是否被误当成因果；
- 必要条件、充分条件和促进条件是否混淆；
- 是否存在能解释同一现象、但会导向不同动作的替代解释；
- 是否用结果反推决定过程必然正确；
- 概念、边界、比较基线和指标代理是否一致。

对关键解释说明：它解释了什么、解释不了什么、还预期观察到什么，以及什么证据会削弱它。不要罗列没有行动差异的所有可能。

### 3. 系统层

把局部答案放回依赖、边界、反馈和上下游关系中。

- 当前问题属于哪个更大活动或系统；
- 改动依赖谁、影响谁、在哪里发生交接；
- 信息、资源、责任和成本怎样流动；
- 局部改善是否把代价转移到别处或未来；
- 是否存在延迟、强化反馈、平衡反馈、阈值或单点依赖；
- 成功以后系统会怎样变化，原方案是否仍然适用。

系统层不是要求绘制完整架构。只展开会改变当前判断的关系，并区分真实存在的结构与模型推测。

### 4. 人性层

检查相关主体的能力、动机、约束、理解和实际行为。

- 谁使用、决定、执行、协作或承担后果；
- 各方知道什么、能够做什么、愿意承担什么；
- 正式角色与实际影响力是否一致；
- 工作量、认知负担、风险、身份和情绪是否改变行为；
- 公开表达、真实行动和已经付出的成本是否一致；
- 方案是否要求人长期做不现实或不可持续的事情。

人性层不能成为猜测心理的许可。动机解释必须由行为、表达或可区分的后续观察支持；没有证据时保留多种解释。

### 5. 意义层

回到问题为什么值得解决、什么才算改善，以及长期仍是否有价值。

- 用户真正要完成什么工作或生活结果；
- 当前指标和交付物是否代表这个结果；
- 谁定义成功，评价标准是否发生变化；
- 方案获得了什么，又牺牲了什么；
- 短期成功是否损害长期目的、关系或能力；
- 问题是否仍值得解决，还是只因已经投入而继续。

意义层不擅自把普通任务上升为人生规划。它只检查当前行动与用户已经表达的目的是否一致，并暴露尚未决定的价值取舍。

## 五维：扩展观察范围

五维不是五种答案，而是把同一个问题旋转到不同方向，检查此前不可见的关系。

### 1. 时间维

观察此前怎样形成、当前处于什么阶段、行动后可能怎样演化。

- 这是一次事件、重复模式还是阶段转换；
- 哪些证据已经过时，哪些影响存在延迟；
- 当前是否有行动窗口，等待和仓促分别付出什么代价；
- 短期、中期和长期结果是否冲突；
- 什么变化会使当前判断失效。

### 2. 利益维

观察收益、成本、风险和工作量怎样分配。

- 谁得到直接收益和选择权；
- 谁承担执行、维护、失败与机会成本；
- 是否有人获得收益，却把风险或劳动转给别人；
- 哪些利益可以共同扩大，哪些真实冲突必须取舍；
- 不行动基线对不同主体分别意味着什么。

利益不只指金钱，也包括时间、注意力、权限、声誉、关系、数据和未来机会。

### 3. 治略维

观察权力、责任、规则、程序和资源配置怎样约束行动。

- 谁有权决定、执行、承诺、否决和验收；
- 责任是否与控制范围、权限和资源相称；
- 正式规则、平台机制和非正式惯例分别怎样起作用；
- 哪些边界可以协商，哪些暂时必须接受；
- 异常、冲突和失败由谁处理，怎样升级。

治略不是只看组织政治，而是检查行动能否在现实权责结构中成立。

### 4. 博弈维

观察其他主体会如何回应，以及回应怎样反过来改变方案。

- 各方有哪些真实可选行动和替代路径；
- 信息是否对称，承诺是否可信；
- 当前规则实际奖励什么行为；
- 一次行动是否改变后续合作、竞争或信任；
- 是否存在局部理性却整体更差的稳定状态；
- 能否通过改变顺序、信息、激励或可行选项创造共同收益。

不预设敌人或零和关系。只有他人的策略回应会改变结论时，才展开博弈分析。

### 5. 哲理维

检查结论依赖的底层概念、前提与世界观。

- “成功”“效率”“公平”“风险”等核心概念在这里怎样定义；
- 当前结论把什么当作不可改变的事实，实际上是否只是惯例；
- 采用了什么关于人、组织、技术或价值的基本假设；
- 结论在什么边界条件下成立，换一种视角会看见什么；
- 是否用抽象原则替代了具体证据。

哲理维用于暴露框架，不用于用格言压过现实，也不要求所有问题形成宏大理论。

## 五层与五维怎样共同工作

五层五维不是两个先后流程，而是一张可以往返的情境坐标系。分析时先从用户当前最关心的问题进入，再寻找会改变结论的交叉关系。例如：

- 信息 × 时间：这项事实现在仍然有效吗；
- 逻辑 × 利益：某个因果解释是否掩盖了成本转移；
- 系统 × 治略：结构依赖是否有明确责任和权限；
- 人性 × 博弈：主体会不会因激励和他方行动改变行为；
- 意义 × 哲理：当前成功定义依赖什么价值前提。

一次分析不需要覆盖全部交叉项。优先处理高影响、可信、会改变取证、比较、取舍或行动的关系。已由一个交叉项说清的问题直接复用，不重复包装。

## 从全面观察收敛到判断

情境分析不能停在“事情很复杂”。完成时应收敛到：

1. 当前问题的核心判断；
2. 原局部答案遗漏了哪些决定性关系；
3. 哪些事实已经成立，哪些仍是解释、价值取舍或未知；
4. 有哪些实质不同且可行的路径；
5. 推荐怎样取舍，关键代价与成立条件是什么；
6. 下一项行动、观察或重审条件是什么。

只有一条可行路径时，说明限制它的事实。未知信息足以改变决定时，优先找一手材料、实际观察或小范围验证；信息价值低于等待成本时，在明确条件下行动。用户只要求研究时停留在研究，只要求诊断时不擅自修复。

## 与战略分析的关系

`situational-analysis` 负责把当前问题看得足够全面，判断方案在现实中是否成立以及当前怎样取舍。

`strategic-analysis` 负责研究局势怎样变化，如何创造、积累、保持和兑现优势。两者可以同时使用：情境分析防止战略建立在遗漏上，战略分析把情境判断转成跨时间的有利轨迹。共享事实和结论，不重复输出两套背景。

## 表达与边界

- 默认给用户结论、决定性遗漏、关键取舍和下一步，不展示完整二十五格分析。
- 简单任务直接完成；显式调用本 Skill 也不能把窄任务膨胀为全面研究。
- 框架只能帮助发现遗漏，不能证明结论正确，也不能替代专业知识、一手证据或用户授权。
- 不因分析了人性和博弈就猜测恶意，不因讨论意义和哲理就把事实相对化。
- 新证据改变问题对象、范围或用途时，检查依赖旧判断的结论和产物，而不只修正当前一句话。
