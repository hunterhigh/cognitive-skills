# 战略分析

帮助用户理解一个局势怎样变化，并设计能够改善当前结果、未来选择和持续适应能力的策略。优势不默认意味着压过别人；它可以来自更准确的认识、更大的可行集、更低的不可补偿风险、更好的合作结构、更快的反馈或更低的长期维持成本。

本 Skill 不承诺知道全局最优。它区分最优解的存在、识别、计算和执行，在当前证据不足时选择能增加信息、保留恢复能力或扩大后续选择的行动。

## 分析对象

战略分析不只处理“选哪个方案”，而是处理一个行动场怎样随时间变化。把战略场暂时表示为：

`Field_t = State + Boundary + Actors + Rules + Resources + Flows + Feedback + Disturbances + Values + Options`

它区分四个相关但不同的对象：

- **位置**：用户当前拥有的资源、信息、关系、权利、能力和退路；
- **轨迹**：若现有反馈持续，位置将朝什么方向变化；
- **能力**：用户产生选项、作出判断、执行、恢复和学习的能力；
- **策略**：在不同观察和回应下选择动作的条件性政策，而不只是一项动作。

一次高收益不自动形成优势；它可能消耗未来选择、增加依赖或形成不可维持的成本。相反，一次局部让步也可能换取信息、合作、能力或更好的长期位置。

## 策略的定义

`Strategy = 在相关时间范围内，根据状态、反馈和他方回应选择并组织行动，以创造、积累、保持或兑现优势条件的连贯政策。`

策略用于获得优势，但优势不应被狭义地理解为当前一步已经得到的显性收益。国际象棋开局可以不立即赢得子力或形成决定性优势，却通过发展、控制、结构、节奏和选择空间提高后续进入有利局面的可能。开局动作的战略价值来自它怎样改变未来可达状态，而不只来自这一步的即时得分。

因此分别判断四种优势：

- **即时优势**：当前已经兑现的收益、资源或行动领先；
- **位置优势**：当前结构使未来有更多高质量选择，或使对手与环境受到更多约束；
- **动态优势**：拥有主动权、反馈速度、学习能力或迫使局势按有利方向演化的能力；
- **终局优势**：在相关时间范围内更可能实现用户真正关心的结果。

四者可以不同时出现。一个动作可能牺牲即时收益以建立位置和动态优势，也可能拥有漂亮位置却无法转换为终局结果。战略分析必须解释优势从哪一层产生、通过什么机制向后转换、需要哪些条件，以及何时应认定转换失败。

目标描述希望到达的状态；战术利用当前局部机会；计划描述预期行动序列；策略则说明在状态变化时如何组织战术和计划，使优势条件逐步形成并被兑现。四者可以重叠，但不能用长期目标或任务清单冒充策略。

## 与情境分析的关系

`situational-analysis` 主要回答：一个判断或方案放进当前现实后是否成立，现阶段应怎样取舍。

`strategic-analysis` 主要回答：局势会怎样发展，可以改变哪些关系，怎样让用户进入并持续保持更有利的轨迹。

两者平行且可以同时启用。情境分析提供当前判断的现实约束，战略分析寻找状态转移、杠杆和适应路径。不要把二者机械排列成固定流程，也不要重复输出两套相同分析。

## 建立动态模型

从用户的实际处境进入，识别当前状态、希望改善的状态、相关主体、资源、约束和时间范围。只建立足以改变策略的模型，不为展示全面而描绘完整世界。

根据问题选择相关关系：

- 哪些部分相互依赖，资源、信息和影响怎样流动；
- 哪些反馈正在强化或抑制结果，是否存在延迟、阈值和意外后果；
- 用户能观察什么、控制什么、影响什么，哪些扰动无法直接消除；
- 其他主体会怎样回应，是否存在合作收益、承诺问题或规则变化；
- 哪些变化能够产生、筛选和保留更有效的做法；
- 当前秩序依靠什么时间、注意力、资金和维护投入，什么正在衰减；
- 不同主体依据什么价值和生活条件理解局势，哪些冲突来自意义结构而非事实错误。

六种思想来源及其误用边界见 [六种现实透镜](references/reality-lenses.md)。它们是按需使用的建模资源，不是六项必填栏目。

## 定义情境中的优势

优势必须相对于当前状态、不行动基线、可行替代和时间范围来判断。识别用户真正希望改善的结果，同时纳入未来状态、相关他人、环境后果和维持成本。不要把一个维度的最大值冒充整体最优。

不要要求每个战略动作立即显示正收益。先判断它是否改善未来可达状态、形成有价值的约束、增强主动权、购买关键信息或建立能够复利的能力。与此同时，不能用“长期优势”保护任何暂时无效的行动：必须给出转换机制、合理时间范围、阶段信号和停止条件。

至少区分：

- 必须守住的可行性和权利约束；
- 当前收益、学习价值和未来选择权；
- 总成本、不可补偿风险和被转移给他人的代价；
- 用户明确提供的价值取舍与仍未确认的解释。

用户决定自己的目标和可接受取舍。可以指出目标冲突、信息缺口或自我损害，但不能用“更懂长期利益”为由夺取用户的决定权。

### 优势从哪里产生

优势通常不是凭空增加，而是来自某些关系被改变：更早或更准地看见重要信息；拥有更多真实可行的选项；以较少投入改变较大结果；比环境变化更快地获得和使用反馈；让各方激励与共同结果更一致；承受扰动后仍留在可行域；形成有效做法的变异、选择和保留；或用可持续维护换取长期复利。

这些机制及其来源、观察信号和常见误用见 [优势机制](references/advantage-mechanisms.md)。只选择能解释当前局势并改变行动的机制。

## 构造并选择策略

先删除在已知条件下明显成本更高、风险更大且没有补偿收益的被支配路径。对真正存在取舍的路径，寻找能改变系统关系而不只是增加努力的干预。

策略可以包括调整反馈、改变信息结构、重新划定边界、创造合作、改变承诺、进行小范围试验、保留选择、建立恢复路径、集中资源、降低维护负担，或有意识地保持现状。不要因为本 Skill 名为“战略”就制造宏大行动。

当关键未知可能改变选择时，比较继续观察、进行可逆试验和立即行动的价值与成本。优先选择能够产生有区分力反馈的下一步，但不能把所有决定拖延成实验。

考虑其他主体时，预判其自主回应而不是把人当成固定参数。合作、竞争和自保可以同时存在；均衡不自动等于公平，获得优势也不要求制造他人劣势。

### 从动作升级为策略

策略至少需要包含顺序和条件：现在做什么；观察什么；对方或环境出现哪种回应时继续、调整、暂停或退出。若所有未来状态都采取同一动作，那更像计划或偏好，不一定是策略。

检查每个阶段承担的作用：是在布置条件、限制下行、诱发回应、获得信息、积累能力，还是兑现已经形成的优势。不能因为某阶段没有立即收益就判断它无效，也不能因为它被称为“布局”就免除阶段验证。

分别检查短期窗口、中期反馈和长期维持。不能用长期愿景逃避当前行动，也不能让短期指标锁死长期能力。必要时构造动作组合：一个动作创造价值，一个动作获得信息，一个动作限制下行风险；但组合只有在净收益高于协调成本时才成立。

### 干预关系而不是堆积努力

优先寻找以下可改变对象：反馈回路、信息可见性、行动顺序、默认选项、承诺结构、激励、系统边界、资源流、变异来源、选择标准、保留机制和维护负担。若推荐只是“投入更多时间、更加坚持、沟通更多”，应说明新增投入通过什么关系产生非线性或持续收益，否则它不是战略杠杆。

检查策略是否把成本外部化给未来的用户、相关他人或维护者。一个只有在忽略补偿、恢复和持续投入时才显得有利的策略，不是完整优势。

## 形成可适应的下一步

给出当前推荐策略时，说明：

- 它试图把什么状态改变为什么状态；
- 决定性杠杆或关系是什么；
- 它为什么优于可行替代与不行动；
- 主要代价、约束和失败方式是什么；
- 什么观察会支持、修正或停止该策略；
- 用户现在能够执行的最小充分行动是什么。

输出服务当前问题，不固定为报告、矩阵或六透镜清单。简单局势直接给结论与下一步；复杂局势只展开会改变策略的动态关系。

结果出现后，将预期与实际比较，区分模型错误、执行偏差、其他主体回应和环境变化。保留有效部分，修改或淘汰失效策略；不要用事后故事证明原判断一直正确。

### 战略失败诊断

当结果不如预期时，区分：边界画错而遗漏关键关系；反馈延迟导致过早判断；用户实际不可控制推荐杠杆；其他主体适应了规则；选择环境奖励了错误行为；新结构维护成本过高；价值与生活条件使策略无法被采用；或策略本身正确但执行偏离。

不要把所有失败归因于“不够坚持”，也不要因一次失败推翻全部方向。找出哪项机制的预测落空，再决定调整动作、改变结构、补证据或退出。

## 边界

- 不把热力学熵直接等同于组织混乱；这里只采用秩序需要持续资源与维护的有限工程含义。
- 不把进化等同于进步、道德改善或弱肉强食；适应只说明在特定选择环境中的保留。
- 不用螺旋动力学给人定级、贴颜色人格标签或证明某种价值更高级。
- 不假定所有互动都是零和，也不因追求合作而忽略真实利益冲突。
- 不以增加步骤、文档、代理或组件代表战略更完整。
- 不接管沟通表达、项目定义、系统架构或工程生成；当主要工作已经属于这些对象时，使用相应专业 Skill。

改进本 Skill 或检查边界时，读取 [案例与检验](references/validation-cases.md)，评价它是否真正改变策略、行动和后续校准，而不是是否复述六门学科术语。
